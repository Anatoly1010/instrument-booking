# Расписание приборов

Локальное веб-приложение для бронирования лабораторных приборов. Каждый прибор имеет свой календарь на день, неделю и месяц. Приборы и брони сохраняются в SQLite.

## Запуск в Windows

Установите Python 3.10 или новее. Из папки проекта запустите:

```powershell
py -3 server.py
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765) в браузере. Оставьте терминал открытым. Для остановки нажмите `Ctrl+C`.

Для запуска на другом порту используйте `py -3 server.py --port 8766`. Параметр `--db` позволяет выбрать другой файл базы. По умолчанию база создаётся в `data/schedule.sqlite3`.

Чтобы дать коллегам доступ для просмотра, запустите отдельный экземпляр с локальным IPv4 и длиной префикса своей подсети. Например, для адреса `192.168.1.10` в подсети `192.168.1.0/24`:

```powershell
py -3 server.py --lan-view 192.168.1.10/24 --port 8768 --db data/schedule.sqlite3
```

Коллеги открывают `http://192.168.1.10:8768/`. Для этого режима нужна существующая база, подготовленная обычным запуском. Он показывает расписание и статистику. Вход и изменение записей доступны на компьютере с сервером и в режиме HTTPS ниже. Если брандмауэр блокирует подключения, разрешите входящий TCP-порт для указанной подсети.

### Редактирование в локальной сети

Запустите `--lan-edit` на отдельном порту с существующей базой и парой файлов HTTPS в формате PEM. В сертификате должен быть указан IPv4-адрес сервера в поле `Subject Alternative Name`.

```powershell
py -3 server.py --lan-edit 192.168.1.10/24 --port 8769 --db data/schedule.sqlite3 `
  --tls-cert data/lan-https/booking-server.pem --tls-key data/lan-https/booking-server.key
```

Коллеги открывают `https://192.168.1.10:8769/`. После входа каждый может редактировать, переносить и отменять брони, созданные под его учётной записью. Администратор может управлять всеми бронями. Если используется внутренний центр сертификации, его корневой сертификат должен быть доверенным на компьютерах коллег. Закрытый ключ сервера храните на сервере. Для входящих подключений разрешите TCP-порт в пределах локальной подсети.

## Первый тест

1. Нажмите «Войти», выберите «Администратор» и введите пароль. Затем нажмите «Добавить прибор» и введите название.
2. В месячном виде дважды щёлкните по дню или нажмите «Новая бронь». По умолчанию время с 09:00 до 20:00. В почасовой сетке можно сразу выбрать время начала.
3. Выберите приборы и сотрудников. Для начала и окончания выберите даты в календаре и введите время в формате `ЧЧ:ММ`. При переносе начала длительность сохраняется. Если отмечен флажок «Весь день», бронь охватывает все выбранные даты, включая дату окончания.
4. Попробуйте сохранить пересекающуюся бронь для того же прибора. Брони могут идти встык. Один интервал можно забронировать у разных приборов.

При загрузке страницы открывается обзор «Все приборы» на четыре недели. Одна общая бронь нескольких приборов показана полосой с диагональными цветами этих приборов. В начале подписи указан резонатор, если он выбран, затем идут участники. Если в дату не помещаются все записи, кнопка со счётчиком рядом с числом открывает остальные. Наведите курсор на запись, чтобы увидеть интервал, или нажмите на неё, чтобы открыть бронь.

Чтобы изменить название, выберите прибор слева и нажмите «Переименовать» рядом с его названием. Брони останутся в календаре этого прибора.

## Учётные записи и доступ

Нажмите «Войти» → «Регистрация» и задайте логин и пароль от 5 символов. В качестве логина можно указать фамилию и имя. Если в справочнике ровно один сотрудник с таким именем, приложение отметит его участником новой брони. Регистр букв и лишние пробелы при сравнении не учитываются. При нескольких совпадениях участника нужно выбрать вручную.

Чтобы потом изменить или отменить свою бронь, войдите до её сохранения. Право на изменение получает учётная запись, которая создала бронь, в том числе когда её владельца нет в справочнике сотрудников. Список участников можно менять без передачи этого права. Гости могут просматривать расписание и создавать брони. Гостевые брони и брони, созданные до появления учётных записей, может изменить или отменить администратор.

Чтобы сменить пароль, войдите и нажмите «Сменить пароль» в шапке. Введите текущий пароль и дважды введите новый. Другие сеансы этой учётной записи завершатся.

### Доступ администратора

Задайте пароль на компьютере с сервером:

```powershell
py -3 server.py --set-admin-password
```

Введите пароль длиной от 12 символов дважды. Для отдельной базы укажите тот же параметр `--db`, с которым запускается сервер. Повторный запуск команды заменяет пароль и завершает действующие сеансы администратора.

В браузере нажмите «Войти» → «Администратор». Администратор может добавлять и переименовывать приборы и резонаторы, редактировать подразделения и сотрудников, менять и отменять любые брони. Сеанс входа действует до выхода, перезапуска сервера или истечения восьми часов.

## Совместные брони

В разделе «Подразделения и сотрудники» можно переименовать четыре лаборатории и отдельный «Отдел ЭПР-спектроскопии», а также добавить сотрудников в любой из списков. В новой брони отметьте приборы и участников. Фильтр по подразделению помогает найти людей и сохраняет уже выбранных участников. Имена, которых ещё нет в списках, можно указать вручную.

У совместной брони одно время и один список участников. Она видна в календаре каждого выбранного прибора. Если хотя бы один прибор уже занят, бронь целиком не сохранится, а приложение укажет конфликтующие приборы.

Вид «4 недели» начинается с понедельника выбранной недели. Кнопки навигации сдвигают вид на неделю. Длительная бронь проходит одной полосой через соседние дни недели, а её подпись показана один раз. Время видно при наведении или в карточке брони.

Кнопка «На всю ширину» скрывает боковую панель, чтобы календарь занял всю ширину окна. Нажмите «Показать приборы», чтобы вернуть панель.

Щёлкните по брони правой кнопкой, чтобы открыть действия. «Копировать» создаёт черновик с прежними параметрами, «Перенести» открывает дату существующей брони, а «Удалить» отменяет её после подтверждения. Для переноса и удаления нужны права автора или администратора.

Автор и администратор могут перетаскивать отдельные брони мышью. В видах «Месяц» и «4 недели» меняется дата, а в видах «День» и «Неделя» время можно сдвигать с шагом 15 минут. Длительность и состав брони сохраняются.

Кнопка «Занятость» показывает количество броней, забронированное время и его долю от календарного времени по каждому прибору за открытый период. Если бронь выходит за границы периода, учитывается только время внутри него.

## Резонаторы

Откройте «Резонаторы» в меню слева, чтобы добавить или переименовать резонаторы. В форме брони можно выбрать резонатор для каждого прибора или оставить поле пустым. Если резонатор уже занят на нужное время, всю бронь нужно перенести на свободный интервал или выбрать другой резонатор.

Время в расписании вводится и показывается как местное время лаборатории. Приложение открывается на компьютере, где запущен сервер.

Чтобы сделать резервную копию, остановите сервер и скопируйте `data/schedule.sqlite3`. База исключена из Git.

## Отправка изменений на GitHub

После локального коммита выполните `git push`. В копии, где `origin` использует SSH, можно отдельно настроить отправку через HTTPS и использовать Git Credential Manager.

```powershell
git remote set-url --push origin https://github.com/Anatoly1010/instrument-booking.git
git push
```

Проверить адрес отправки можно командой `git remote get-url --push origin`.
