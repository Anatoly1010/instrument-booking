# Расписание приборов

Локальное веб-приложение для бронирования лабораторных приборов. Каждый прибор имеет свой календарь на день, неделю и месяц. Приборы и брони сохраняются в SQLite.

## Запуск в Windows

Установите Python 3.10 или новее. Из папки проекта запустите:

```powershell
py -3 server.py
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765) в браузере. Оставьте терминал открытым. Для остановки нажмите `Ctrl+C`.

Для запуска на другом порту используйте `py -3 server.py --port 8766`. Параметр `--db` позволяет выбрать другой файл базы. По умолчанию база создаётся в `data/schedule.sqlite3`.

## Первый тест

1. Нажмите «Добавить прибор» и введите название.
2. Откройте календарь прибора и нажмите на час в сетке или «Новая бронь».
3. Задайте начало, окончание, имя и при необходимости комментарий. Чтобы изменить время или удалить бронь, откройте её из календаря.
4. Попробуйте сохранить пересекающуюся бронь для того же прибора. Брони могут идти встык. Один интервал можно забронировать у разных приборов.

Чтобы посмотреть занятость всех приборов за месяц, нажмите «Все приборы» в списке слева. В каждой дате у занятого прибора есть одна цветная строка. Если броней несколько, рядом указано их количество. Наведите курсор, чтобы увидеть интервалы, или нажмите на строку, чтобы открыть брони. Нажмите на число месяца, чтобы создать новую бронь на этот день.

Чтобы изменить название, выберите прибор слева и нажмите «Переименовать» рядом с его названием. Брони останутся в календаре этого прибора.

## Совместные брони

В разделе «Лаборатории и сотрудники» можно переименовать четыре начальных списка и добавить сотрудников. В новой брони отметьте приборы и участников. Фильтр по лаборатории помогает найти людей и сохраняет уже выбранных участников. Имена, которых ещё нет в списках, можно указать вручную.

У совместной брони одно время и один список участников. Она видна в календаре каждого выбранного прибора. Если хотя бы один прибор уже занят, бронь целиком не сохранится, а приложение укажет конфликтующие приборы.

Вид «4 недели» начинается с понедельника выбранной недели. Кнопки навигации сдвигают вид на неделю. В общем обзоре строка содержит участников и время, а длительная бронь соединяет соседние даты одной календарной недели.

Время в расписании вводится и показывается как местное время лаборатории. Тестовая версия открывается на компьютере, где запущен сервер, и использует общий доступ к расписанию без учётных записей.

Чтобы сделать резервную копию, остановите сервер и скопируйте `data/schedule.sqlite3`. База исключена из Git.
